# Contributing to Firework-detonator

Thank you for your interest in contributing to Firework-detonator!

Firework-detonator is an open-source project, and contributions, suggestions, bug reports, and improvements are welcome.

However, this repository follows an owner-maintained contribution model.

## How You Can Contribute

There are two primary ways to contribute.

### 1. Creating Issues

You are welcome to create GitHub issues to:

- Report bugs.
- Suggest new features.
- Recommend improvements.
- Ask questions about the project.
- Report compatibility problems.

Please provide a clear description and any relevant information when creating an issue.

### 2. Submitting Pull Requests

You may submit pull requests to propose changes to the project.

The recommended workflow is:

1. Fork the Firework-detonator repository.
2. Clone your fork to your local machine.
3. Make your proposed changes in your fork.
4. Test your changes.
5. Commit and push your changes to your fork.
6. Open a pull request against the original Firework-detonator repository.
7. Wait for the repository owner's review.

## Repository Permissions

**Firework-detonator is maintained exclusively by its repository owner.**

To protect the integrity and consistency of the project:

- Contributors cannot push commits directly to the original repository.
- Contributors cannot directly modify protected branches.
- All code changes must be submitted through pull requests.
- Pull requests are proposals, not automatic changes to the project.
- The repository owner has the final authority to approve, reject, or merge pull requests.

Submitting a pull request does not guarantee that the proposed changes will be accepted.

## Code Quality

When submitting changes, please:

- Keep your code readable and maintainable.
- Follow the existing project structure and conventions.
- Avoid introducing unnecessary dependencies.
- Test your changes before submitting them.
- Clearly explain what your changes accomplish.

## Feature Requests

Before implementing a major feature, consider opening an issue to discuss the idea first.

This helps ensure that proposed features align with the project's direction.

## Final Note

Thank you for helping improve Firework-detonator!

Your contributions and feedback are appreciated. While the repository remains under the direct control of its owner, the project welcomes community participation through issues and pull requests.
